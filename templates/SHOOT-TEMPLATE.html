Block 1

Theme statement

One sentence. Who is this shoot for, what is the deliverable, what is the mood.

Pass test — if you read your theme back and it doesn't tell you what to LOCK, it's too vague. Rewrite.
Block 2

Polish point

Pick ONE point on the spectrum. That choice tells you what to lock hard and what to leave loose.

  • Studio — full polish, every variable controlled
  • Editorial — pro craft, slightly relaxed
  • Lifestyle — feels authentic, still styled
  • UGC — phone-shot register, anti-aesthetic on purpose
  • Documentary — observed, never staged
Why this point — one sentence linking polish to deliverable

Lock checklist — every box checked before you write the shot table

  • Identity reference saved as a Higgsfield job ID or uploaded file
  • Camera + lens written as a complete sentence (not a vibe word)
  • Color grade specifies a real reference film / look
  • Wardrobe family is a FAMILY, not a single outfit
  • Anti-keywords name the failure modes you've actually seen
Block 4

Shot table

One row per shot. Columns are the slots that CHANGE. Same column names as your bucket page.

The same-scene-multiple-angles trick. Allow 2–3 rows at the SAME setting where only the composition column changes (wide / profile / hands close-up). You're building a shoot, not a slideshow.

Final QC

Ship / no-ship pass

Run through this with the full grid in front of you. If any answer is NO, the set isn't done.

Coherence — the locked half held

same person/product, same grade, same lens family, same wardrobe lane

  • Does the same person/product appear in every shot?
  • Does every shot share the same color grade — same blacks, warmth, skin tone?
  • Does the lens choice feel consistent — no wide-angle next to a long-portrait?
  • Has the wardrobe / surface family stayed inside its lane?

Variety — the variable half worked

earn the scroll, build a sequence, prove the same-scene-different-angle move

  • Does each shot earn its place — different setting, light, or composition?
  • Are at least 2 shots same-scene-different-angle, not just N different scenes?
  • Does the set read as a sequence — opener, middles, closer?

The ship test

  • Could a client paste this grid into a deck and call it a campaign?
  • Would you be proud to caption it with your name?
Notes
