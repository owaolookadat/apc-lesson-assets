The Project Sheet

One document. Eight blocks. Filled top-down before you generate a single image. By the time the last QC box is green, the project is shippable — generation is just paste-and-fire.

!

The rule. If any block is empty or vague, don't open the generator yet. Go back. This sheet is what separates a tinkerer from a working AI creator.

Block 1

Concept + brief

5 min · no deps

Every project starts as a sentence. If you can't write it in one paragraph, you don't know what you're making yet.

One-paragraph concept — what, why, who, format, length
Common skip — starting to generate before you can name the concept in one paragraph. The shoot becomes whatever the first prompt produces, and the project never recovers a coherent shape.
Block 2

Distribution plan

15 min · no deps

The hook line dictates shot 1. The caption shapes what the carousel needs to pay off. Distribution before storyboard, every time.

Block 7

Audio brief

15 min · no deps

If the post has sound, audio is half the deliverable. If it's silent, write "(silent)" — explicit, not assumed.

VO script — clean paste block (spoken words only)
VO script — Eleven v3 tagged block (inline [warm] [excited] per beat)
Music registergenre + energy + reference track
SFXkeyed to shot numbers
Common skip — "I'll figure out audio later." Later never comes; the post ships with random royalty-free music that fights the visuals.
Block 8

QC checklist — pre-publish gate

5 min · depends on all

Any unchecked box = do not post. This is the discipline gate.

Identity locked across every shot (same subject, no drift)
Brand colors consistent across the set
Caption + hashtags ready (Block 2 filled and frozen)
CTA + DM funnel keyword in place
Posting time + platform set
If video — audio mixed + captions burned in
If carousel — card order finalized + card 1 is the hook
Final shot includes save-or-share moment
All boxes ✓ = ship. Any box ⚪ = do not post yet.
Common skip — posting when it "looks done." 24 hours later you notice the subject in shot 3 doesn't match shot 1. QC catches this before it ships.
