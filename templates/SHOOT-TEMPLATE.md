## FINAL QC — ship / no-ship pass

> Before the set goes anywhere, run through this with the full grid in front of you. If any answer is NO, the set isn't done.

### Coherence (the locked half held)
- [ ] Does the same person/product appear in every shot?
- [ ] Does every shot share the same color grade — same blacks, same warmth, same skin tone?
- [ ] Does the lens choice feel consistent — no wide-angle next to a long-portrait?
- [ ] Has the wardrobe / surface family stayed inside its lane?

### Variety (the variable half worked)
- [ ] Does each shot earn its place — different setting, light, or composition?
- [ ] Are at least 2 shots same-scene-different-angle, not just N different scenes?
- [ ] Does the set read as a sequence — opener, middles, closer?

### The ship test
- [ ] Could a client paste this grid into a deck and call it a campaign?
- [ ] Would you be proud to caption it with your name?
