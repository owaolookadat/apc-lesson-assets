# THE PROJECT SHEET

**One document. Eight blocks. Filled top-down BEFORE you generate a single image. By the time the last QC box is green, the project is shippable — generation is just paste-and-fire.**

> **The rule:** if any block is empty or vague, don't open the generator yet. Go back. This sheet is what separates a tinkerer from a working AI creator.

## How the 8 blocks fit together

| # | Block | Captures | Time | Depends on |
|---|---|---|---|---|
| 1 | **Concept + brief** | One paragraph — what, why, who, format, length | 5 min | nothing |
| 2 | **Distribution plan** | Hook line + caption + hashtags + CTA + posting plan | 15 min | nothing |
| 3 | **Locked assets** | Character sheets + product sheets + brand kit references | 10 min | (sheets must exist) |
| 4 | **Storyboard** | Frame-by-frame description grid (text first, stills later) | 20 min | Block 3 |
| 5 | **Shotlist** | Numbered table — prompt JSON + refs + status per shot | 30 min | Blocks 3 + 4 |
| 6 | **Motion brief** *(video only)* | Camera move + subject action + duration + transition | 15 min | Block 5 |
| 7 | **Audio brief** | VO script + music register + SFX, OR "(silent post)" | 15 min | nothing |
| 8 | **QC checklist** | Pre-publish gate | 5 min | all blocks |

> **Why distribution (2) comes before storyboard (4):** the hook line dictates shot 1. If you don't know the caption, you can't compose the opening frame.

## BLOCK 8 — QC checklist — pre-publish gate

> Any unchecked box = do not post. This is the discipline gate.

- [ ] Identity locked across every shot (same subject, no drift)
- [ ] Brand colors consistent across the set
- [ ] Caption + hashtags ready (Block 2 filled and frozen)
- [ ] CTA + DM funnel keyword in place
- [ ] Posting time + platform set
- [ ] If video: audio mixed + captions burned in
- [ ] If carousel: card order finalized + card 1 is the hook
- [ ] Final shot includes save-or-share moment

**All boxes ✓ = ship.** Any box ⚪ = do not post yet.

**Common skip to avoid:** posting when it "looks done." 24 hours later you notice the subject in shot 3 doesn't match shot 1. QC catches this before it ships.

## Where this fits in the curriculum

| Doc | Scope | When you use it |
|---|---|---|
| **Project Sheet (this file)** | One posted deliverable | Once per project |
| **Shoot Template** | One shoot inside a project | Once per shoot block — a project can contain multiple shoots |
| **F-Sheet** | One character identity | Once per character; reused across many projects |
| **F-PSheet** | One product identity | Once per product; reused across many projects |

Three scopes. **Project Sheet** is the outer wrapper. **Shoot Template** is the middle. **F-Sheet / F-PSheet** are the reusable atoms.
