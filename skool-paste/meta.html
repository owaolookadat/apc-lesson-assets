What this section is

Every paying client buys a shoot, not a shot. A shoot is a coherent set of images that share a visual identity — same person, same world, same grade — across a deliberate list of moments. The Frameworks Library teaches the one thinking pattern that builds any kind of shoot, then gives you paste-ready templates for the most common ones.

F1–F5 taught you how to direct a single still and a single clip. This is how you direct a set.

The universal pattern

Every shoot has two halves — a locked half and a variable half. The locked half is what gives the set its coherent identity. The variable half is what gives it variety.

Five boxes. Four arrows. That diagram is the whole skill.

Stage 1 — the Theme

Before any prompt, you decide the theme: who's the client, what's the deliverable, what mood. A theme is one sentence:

An editorial portrait series of a brand founder —
warm, restrained, Kodak Portra grade, six shots
across studio, work, and life moments.

The theme is what decides the split. Same model, same grade across every shot = locked. Different setting, lighting, pose per shot = variable. The theme tells you which ingredients belong on which side.

Stage 2 — the Master Setup Recipe

The locked half goes into one JSON — the master setup. Every shot in the set will paste this as its base and only swap the variable slots.

{
  "image_type": "editorial documentary photograph",
  "subject": "<character lock — see reference image>",
  "setting": "<SLOT>",
  "lighting": "<SLOT>",
  "camera_lens": "Sony A7R V, 50mm f/2.0, sharp focus on the eyes, shallow depth",
  "color_grade": "warm-dominant, raised blacks, fine grain, Kodak Portra warmth, no heavy LUT",
  "no_cinematic_lut": true,
  "no_anamorphic_flare": true,
  "no_ai_tells": true,
  "identity_lock_strength": "high",
  "character_reference": "<attached>"
}

The <SLOT> markers are the variable half. Everything else holds.

Worked example — what Row 1 actually looks like

The recipe + the shot table feel abstract until you see one row turned into a real prompt. Here is Row 1 of the table above, with every <SLOT> from the recipe replaced by Row 1's values. This is the string you paste into your generator.

{
  "image_type": "editorial documentary photograph",
  "subject": "<character lock — see reference image>",
  "setting": "clean studio, bone-white seamless backdrop",
  "lighting": "soft natural daylight, key from camera-left, gentle fill",
  "pose": "three-quarter portrait, eyes on camera, relaxed shoulders",
  "camera_lens": "Sony A7R V, 50mm f/2.0, sharp focus on the eyes, shallow depth",
  "color_grade": "warm-dominant, raised blacks, fine grain, Kodak Portra warmth, no heavy LUT",
  "no_cinematic_lut": true,
  "no_anamorphic_flare": true,
  "no_ai_tells": true,
  "identity_lock_strength": "high",
  "character_reference": "<attached>"
}

Compare it to Stage 2: the locked keys are byte-for-byte identical. Only three values changed — setting, lighting, pose — because those are the columns the shot table varies. Row 2 will paste the same JSON and change only those same three lines. That is the entire trick.

Stage 4 — Generate row by row

Each row gets one generate call: master recipe + this row's slot values + character reference. Six rows = six generations. Same identity, same grade, six different moments.

This is where it pays back. You don't write six prompts — you write one recipe and fill six rows. When the brief changes (new client, new mood), you keep the table structure and rewrite the recipe.

Stage 5 — the Coherent Set

You now have a deliverable. Six images that read like one shoot — because the model was held constant on every locked ingredient. The variety is deliberate, not accidental.

Why this matters commercially. A magazine, a brand, an agency — they don't pay you per image. They pay you for a set that ships as a campaign. Mastering the locked/variable split is what turns generations into shoots, and shoots into deliverables.

Decision framework — picking your split

Before you write the recipe, two decisions tell you what to lock.

Decision A — what's the deliverable for?

If the deliverable is…You're shooting…
An ad campaign / brand launchPolished commercial — lock lighting + grade hard
Social organic / creator contentUGC — lock identity but variable phone-feel
Website / press / lookbookEditorial — lock grade + lens, variable setting
Catalog / e-commerceStudio packshot — lock everything except the SKU

Decision B — where on the polish spectrum? One axis. Pick a point. That choice drives every locked ingredient.

The further left you sit, the harder you lock lighting + grade. The further right you sit, the more you lock identity and let the rest feel hand-held.

Polished or raw — both are valid choices

The spectrum used to map to "good versus bad." That is no longer true. Modern commercial work — beauty, wellness, fashion, hospitality — is actively choosing realism. Visible pores, micro-asymmetry, uneven light, slight imperfection. Brands buy it because audiences read it as real, and real outperforms perfect in feeds and conversion.

When you write your recipe, decide on purpose which side you're shooting.

If you want polishedIf you want raw
Lock studio lighting and a clean LUT-style gradeLock identity hard, leave light uneven
Wardrobe styled, hair done, makeup deliberateWardrobe casual, hair natural, no glam
Anti-keywords: anti-grain, anti-blur, anti-imperfectionAnti-keywords: NO beauty filter, NO skin smoothing, NO studio polish, NO DSLR look
Add to prompt: "campaign quality, magazine sharp"Add to prompt: "visible skin texture, pores, micro-asymmetry, true-to-life skin tones"
The skin-texture phrase is the single most important addition for "raw." Without it, every model tends to default to polished. With it, the same recipe produces a real human you'd believe the photo of.

Same scene, multiple angles — the move pros use

A working shoot does not give you one shot per scene. It gives you 2–4 angles of each setup. Wide establishing, profile, close-up of hands, reverse over-the-shoulder. Same coffee, same window, same light — the variation is composition, not setting.

When you write your shot table, allow yourself rows at the same setting where only the composition column changes. The locked half holds; the variable half barely moves; the set reads as a shoot instead of a slideshow of separate moments.

Where to go next

The pattern is universal. The slot names are what change per bucket. Go to the bucket that matches your shoot:

  • Model Shoots — humans as subject. Editorial portrait, fashion lookbook, UGC, beauty, athletic.
  • Product Shoots — objects as subject. Hero / macro, catalog, lifestyle product, premium, jewelry, tabletop.
  • Scene & Architecture — place as subject. Exterior, interior, hospitality, travel.
  • Food — dish as subject. Editorial food, restaurant menu, cookbook, drinks, ingredient flat-lay.
  • Sport & Action — movement as subject. Studio action, on-location, behind-the-scenes.
  • Conceptual — idea as subject. Sci-fi, fantasy, editorial concept.

Each bucket page = the workflow for that kind of shoot + a prompt bank of paste-ready setups for the specific scenarios you'll actually be briefed on.

Same pattern, different slots. A product shoot doesn't have a "pose" slot — it has an "angle" and a "backdrop" slot. A scene shoot has a "time of day" slot. The thinking pattern is identical; the columns of the shot table change. Every bucket page makes its column set explicit.
