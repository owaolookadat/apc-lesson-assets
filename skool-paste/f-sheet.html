F-Sheet — Build a Character Sheet from One Photo

What you'll learn

How to take one input photo of a person and produce a multi-view character sheet that becomes their identity reference for every shoot you ever do for them. The single highest-leverage asset in the entire workflow: build it once, reuse it on every framework, every ad, every campaign.

In F3 you learned to use a cropped face as a reference. This lesson teaches you to build the sheet that face slots into.

The result you're building (one input → this sheet)

Five views: front / three-quarter left / profile / three-quarter back / hero close-up. Same identity, same wardrobe, same lighting, same scale. One asset, infinite downstream shoots.

The 3-tier sheet

TierWhat it locksBuild effort
5-view sheetFace + body + proportions across angles1 generation
4-expression sheetNeutral + smile + serious + talking1 generation, optional
4-wardrobe sheetMultiple outfits for the same person1 per wardrobe family

The 5-view is non-negotiable. The other two are added when the brief demands them.

Recipe F.SHEET.01 — 5-view from one photo

JSON-structured for Nano Banana Pro. Attach the client's one input photo as the reference. Returns a single composite image with 5 views.

{
  "image_type": "studio character reference sheet, single composite image",
  "subject": "the person from the reference image — do not redescribe their face",
  "layout": "horizontal grid of 5 views, equal spacing, clean bone-white seamless backdrop",
  "views_left_to_right": [
    "FRONT view, full body, arms relaxed at sides, neutral expression",
    "THREE-QUARTER LEFT view, body angled 45 degrees to the left",
    "PROFILE LEFT view, full side profile",
    "THREE-QUARTER BACK view, looking back over the right shoulder",
    "HERO CLOSE-UP head-and-shoulders portrait, eyes on camera, neutral"

  "wardrobe_lock": "<SLOT — one outfit, identical across all 5 views>",
  "lighting": "single soft studio key from camera-left, gentle fill, identical across all 5 views",
  "camera_lens": "Sony A7R V, 80mm f/2.8, sharp throughout, faithful skin tones",
  "color_grade": "clean editorial, faithful tones, no LUT, no warmth bias",
  "same_identity_across_all_views": true,
  "same_wardrobe_across_all_views": true,
  "same_lighting_across_all_views": true,
  "same_scale_across_all_views": true,
  "no_different_person_between_views": true,
  "no_color_shift_between_views": true,
  "no_facial_description": true,
  "identity_lock_strength": "high",
  "anti_drift_reinforcement": [
    "every view must show the SAME person — same face, same body, same hair",
    "every view must show the SAME outfit, identical wardrobe top to bottom",
    "the sheet is a single coherent reference asset, not five separate generations"
  ]
}
Why one composite, not five separate generations. When you ask for 5 angles in one composite image, the model holds identity tighter than separate generations — it's locking them against each other inside the same render. Downside: composition is sometimes uneven. When that happens, fall back to 5 individual generations and tile them.

Workflow (step by step)

  1. Get your input. Pick the single cleanest, most forward-facing photo. 512×512 minimum, in focus.
  2. Pick the wardrobe. Decide ONE outfit. It appears on every view. Choose neutral (cream knit, black tee) so the sheet stays usable across many briefs.
  3. Open Higgsfield → Nano Banana Pro. Attach the input photo. Aspect 16:9, resolution 2k, variants 2.
  4. Paste Recipe F.SHEET.01. Fill the wardrobe_lock slot.
  5. Generate. Pick the cleaner of the two variants. That's your sheet.
  6. Save it named after the identity (anna-sheet.jpg). Reuse it on every downstream shoot.
