The Shoot Template

Every shoot you run starts as a blank version of this page. You fill it in before you write a single prompt. By the time the template is full, the shoot is already designed — generation is the easy part.

How to use it. Copy the five blocks below into a doc. Fill them in for your shoot. When every block is complete, you are ready to generate. If any block is empty or vague, you are not — go back.

Block 1 — Theme statement

One sentence. Who is this shoot for, what is the deliverable, what is the mood.

The same-scene-multiple-angles trick. Pro shoots almost never give you one shot per scene. They give you 2–4 angles at each setup. When you fill the table, allow 2–3 rows at the same setting where only the composition column changes — a wide, a profile, a close-up of hands. You're building a shoot, not a slideshow of scenes.

Final QC — the ship/no-ship pass

Before the set goes anywhere, run through this list with the full grid in front of you. If any answer is no, the set isn't done.

Coherence (the locked half held)
  • ☐ Does the same person/product appear in every shot?
  • ☐ Does every shot share the same color grade — same blacks, same warmth, same skin tone?
  • ☐ Does the lens choice feel consistent — no wide-angle next to a long-portrait?
  • ☐ Has the wardrobe / surface family stayed inside its lane?
Variety (the variable half worked)
  • ☐ Does each shot earn its place — different setting, light, or composition?
  • ☐ Are at least two shots same-scene-different-angle, not just N different scenes?
  • ☐ Does the set read as a sequence — opener, middles, closer?
The ship test
  • ☐ Could a client paste this grid into a deck and call it a campaign?
  • ☐ Would you be proud to caption it with your name?

Now run it

Pick a real client (yourself counts). Fill the five blocks above. Generate the table. Pass QC. Ship the set.

The framework is universal. The template is the discipline that makes you use it every time, instead of one-shotting prompts and getting one-shot results.
