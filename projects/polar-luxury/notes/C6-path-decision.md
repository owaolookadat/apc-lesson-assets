# C6 — VO Path Decision

PROJECT: Polar Bear × Heritage Winter Luxury · IG Reel · 30 sec

## DECISION: PATH A (Higgsfield Veo 3.1 baked-in audio)

## REASONING (decision matrix)

| Question | Answer | Path A or B? |
|---|---|---|
| Is this my first reel ever shipped? | Yes (ship-gate test) | A |
| Do I already have a recognizable on-camera voice (>10k audience)? | No | A |
| Will I produce 10+ reels per month right now? | No (single test reel) | A |
| Does the client require a specific voice register? | No spec given | A |

**0 yeses for Path B → Path A is the right call.**

## REGISTER DISCIPLINE (Path A common-skip 3)

Used the SAME voice descriptor across beats 1–4 ("a deep dry / matter-of-fact / low knowing male voice") so Veo gives one consistent speaker. Beat 5 shifts to "a warm confident male voice" as the closer turn — exactly two registers across the reel, not five.

## WHY NOT PATH B HERE

Path B (Eleven v3 voice clone) adds 20 min/reel for the voice-clone setup, then 5 min per reel for the audio mix in CapCut (since Veo won't be baking music + SFX). For a single test reel with no existing brand voice, that's pure cost with zero payback. Default-of-defaults: stay on A.

GATE: ☑ decision documented (A) with reasoning · ☑ Path A 5 clips share consistent baked-in voice descriptor · ☑ Path B steps not required for this project
