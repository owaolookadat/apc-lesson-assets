# Section 1 — Sheet prompts

## 1.1 — F-Sheet (Character Sheet)

**Tool:** Higgsfield web UI · Nano Banana Pro · 16:9 · 2K

**References to attach:**
- Reference 1: A single anchor portrait of your subject (single-view, sharp, clear face/identity features)

**Adapt to your concept:**
- Replace albino/heterochromia features with YOUR subject's identity markers
- Keep the 5-panel structure (eye macro, front face, 3/4 face, full body, profile)
- The eye macro panel is for whatever defining facial feature your subject has

**Paste-ready template:**

```
F-SHEET (Character Sheet) — 5-panel canonical identity lock for the subject in the attached reference image. Face-weighted because the face is the canonical brand asset for this project.

REFERENCE: use as IDENTITY reference. Preserve [subject's distinctive features — skin tone, hair color/texture, distinctive facial features, freckles/marks, etc.] from the reference exactly.

[OPTIONAL — DEFINING FEATURE OVERRIDE]
If your subject has a feature you want to AMPLIFY beyond what the reference shows (e.g. specific eye color, distinct heterochromia, makeup style), specify it here as an explicit override:
"Override: [feature] must be [specific spec]. This is the canonical look for this character."

ONE composite image, 5 panels in a horizontal row, equal-width columns separated by thin black gutters.

PANEL 1 — EYE MACRO / DEFINING FEATURE: Extreme close-up showcasing the polarizing identity hook. [If eyes are the feature: frame from upper brow to upper cheekbone, both eyes visible side-by-side, iris detail crisp.]

PANEL 2 — FRONT FACE CLOSE-UP: Head and shoulders, facing camera directly, both eyes locked to lens.

PANEL 3 — 3/4 FACE: Head and shoulders, model rotated 30-45 degrees showing cheekbone structure and jawline.

PANEL 4 — FULL BODY FRONT: Full body from head to mid-shin, neutral standing pose, arms relaxed at sides. [Describe wardrobe: e.g. "wearing the cloud tube-top dress visible exactly as in reference"]

PANEL 5 — PROFILE PORTRAIT: Head and shoulders in full profile, showing jawline silhouette, hair flow, ear, eye in profile.

IDENTITY LOCK across all 5 panels:
- Same face, bone structure, age
- Same hair color and texture
- Same skin tone and texture
- Same [defining feature]
- NO drift between panels — should be unmistakably the same person 5 times

BACKGROUND: All 5 panels on clean neutral mid-grey seamless studio background (#888888). Same soft 3-point studio lighting across all panels — 5400K daylight balance.

REGISTER: High-fashion editorial casting sheet — Vogue / i-D / Dazed register. PHOTOGRAPHY only.

NO airbrushed skin — preserve pores, texture, and natural imperfections from reference. NO drawn-on perfect features. NO uncanny valley. NO CGI. NO illustration. NO real brand wordmarks.
```

# Section 3 — Video motion prompts

## 3.1 — Kling 3.0 universal slow-mo prefix

Every video prompt starts with this:

```
Slow-motion luxury fashion film. Phase One IQ4 medium-format aesthetic. [Project register — Tim Walker / commercial / etc].

Camera move: [SPECIFIC MOVE — slow arc / side-track / push-in / static / drift / pull-back]. Smooth and continuous over the full clip duration. NO snap movements.

Subject motion: [What the subject does — usually still or minimal motion].

Material/cloud behavior (if applicable): [Atmospheric drift rules — what's allowed vs banned].

Other motion: atmospheric haze drifts slowly. Background equipment stays STATIONARY.

NO fast camera moves. NO dramatic motion. NO snap movements.

Hyperrealistic cinematic register. PHOTOGRAPHY, not animation.
```

## 3.2 — Per-beat motion prompts (Cloud Fashion Week)

| Beat | Camera move | Subject motion | Key constraint |
|---|---|---|---|
| B1 | Slow horizontal arc 90° around subject | Still + slow blink at sec 3 | Atmospheric cloud drift |
| B2 | Slow side-tracking dolly | Still in profile | Atmospheric cloud drift |
| B3 | Slow continuous push-in to face | Slight gaze shift + slow blink at sec 13 | Heterochromia preserved |
| B4 | Locked static | TOTALLY STILL — no blink | Eye colors preserved |
| B5 | Subtle slow upward drift | Material breathes | Cloud holds shape |
| B6-fashion | Continuous pull-back | Still | All elements unified |
| B6-desk | Continuous pull-back | Silhouette still | Laptop screen blank |

## 3.3 — Doctrines for video motion prompts

**Slow-mo register:** every motion is slow. No whip pans, no snap zooms.

**Blink doctrine:**
- Face-size in frame > 30% → blink (no-blink = uncanny waxwork)
- Macro-only eyes → NO blink (stillness IS the action)

**End-frame trick:** Use end-frame in Kling to LOCK identity / cloud stability — but it also LOCKS camera position. Use only when you don't need camera movement.

**Material physics:** Specify what the material DOES and DOESN'T do. AI defaults to fabric physics on body-mounted volumes.

# Section 4 — VO prompts

## 4.1 — Eleven v3 paste block (Cloud Fashion Week)

```
[slow] [calm] There's no model.

[slow] [calm] There's no dress.

[slow] [calm] There's no studio.

[slow] [thoughtful] There's no shoot.

[slow] [confident] AI Production Club. [thoughtful] Studio quality... without the studio.
```

## 4.2 — VO script structure for YOUR reel

Use the "no X / no Y / no Z" rhythm:
1. **Line 1:** "There's no [thing in B1 that doesn't exist]."
2. **Line 2:** "There's no [thing in B2 that doesn't exist]."
3. **Line 3:** "There's no [thing in B3 that doesn't exist]."
4. **Line 4:** "There's no [the most polarizing thing]."
5. **Line 5:** "[Brand name]. [Defensible claim line]."

## 4.3 — VO defensibility check

Before recording your final VO line, ask:
- **Could someone with $$$ technically pull this off?** If yes — your claim is undefensible.
- Pivot to a CLAIM that's true: cost-based ("no studio could afford"), time-based ("built in an afternoon"), or method-based ("studio quality without the studio").

# Section 6 — Higgsfield + Kling settings reference

## Higgsfield Nano Banana Pro (still gen)

| Setting | Default value | When to adjust |
|---|---|---|
| Aspect | 9:16 for reel beats; 16:9 for sheets | — |
| Resolution | 2K | Upscale x2 to 4K AFTER approved (Topaz model) |
| Variations | 2 (not 4) | More variations = more drift with multi-ref |
| Upscale model | Topaz (NOT Topaz Generative) | Generative invents new details = identity drift |
| Face enhancement | OFF | Smooths out freckles, normalizes features |

## Kling 3.0 (image-to-video)

| Setting | Value | Why |
|---|---|---|
| Mode | Image-to-Video | Source image controls identity |
| Aspect | 9:16 | Match reel aspect |
| Duration | 5s (or longer if available for headroom) | Standard |
| Quality | 4K | Best output |
| Multi-shot | OFF | We want continuous take |
| Sound | **OFF** | Path B doctrine — recorded VO, not Kling audio |
| Enhance | ON for motion beats / OFF for static beats | Enhance adds motion |
| End frame | EMPTY usually | Only use when you need to lock identity AND camera is static |
